# OpenTome

An always-on personal agent. Work in progress, built in public.

It started from my [Boot.dev](https://www.boot.dev) "Build an AI Agent" project: an agent loop that calls tools (list files, read a file, write a file, run Python) through an OpenAI-compatible API (OpenRouter).

Next: run it on a free local model with Ollama, give it memory, and talk to it from Telegram.

## Status
Early. Not ready for anyone else to run yet.
